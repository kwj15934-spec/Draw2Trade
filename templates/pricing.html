자주 묻는 질문

결제는 어떻게 진행되나요?
신청 시 안내되는 계좌로 월간 ₩8,900 또는 연간 ₩85,000을 입금하시면 됩니다. 입금자명을 신청 시 입력하신 이름과 동일하게 적어 주셔야 자동 매칭이 가능하며, 신청 후 48시간 내 미입금 시 신청은 자동 취소됩니다.
결제 후 언제 Pro가 되나요?
금융결제원 오픈뱅킹 API 로 입금 내역을 자동 확인합니다. 입금 후 평균 1~3분 내 Pro 가 활성화되며, 신청 페이지에서 실시간 상태가 표시됩니다. (자동 매칭 활성화 전까지는 관리자 확인 후 영업시간 내 1~12시간 소요됩니다.)
7일 무료체험은 어떻게 되나요?
신규 가입 시 자동으로 7일 동안 Pro 기능을 무료로 이용할 수 있습니다. 별도의 결제 등록 없이 자동으로 만료되며, 계속 이용을 원하시면 Pro 를 결제해주세요.
구독 기간 / 자동 갱신은 어떻게 되나요?
월간은 30일, 연간은 365일 동안 Pro 가 유지됩니다. 자동 갱신은 없으며, 만료 전 다시 결제하시면 기간이 연장됩니다. 갱신 알림 메일을 만료 3일 전 발송해드립니다.
세금계산서 발급이 가능한가요?
사업자등록번호와 함께 문의로 요청 주시면 발급해드립니다. 표시 가격은 부가세 포함입니다.
환불이 가능한가요?
결제 후 7일 이내이며 아래 조건을 모두 충족하는 경우 전액 환불이 가능합니다.

· Pro 기능 사용 이력이 없는 경우
· 결제 후 7일 이내 요청한 경우

환불은 환불 신청 페이지에서 접수해 주세요. 확인 후 영업일 기준 3일 이내 처리됩니다.
신용카드 결제도 가능한가요?
현재는 국내 계좌이체만 지원합니다. 카드 결제는 추후 지원 예정입니다.
