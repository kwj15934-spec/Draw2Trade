Q&A · 알아두면 좋은 정보

Draw2Trade가 제공하는 서비스의 성격, 법적 지위, 데이터 출처, 요금제, 핵심 기능에 대한 답변을 정리했습니다.

서비스 소개

QDraw2Trade는 어떤 서비스인가요?▶

Draw2Trade는 사용자가 차트 위에 직접 그린 가격 패턴(곡선)과 가장 유사한 과거 종목·구간을 통계적으로 찾아주는 차트 패턴 매칭 도구입니다.

본질은 "패턴 검색 엔진 + 시각화 도구"이며, 투자 자문이나 매매 추천 서비스가 아닙니다.

Q어떤 사람들에게 유용한가요?▶

차트의 시각적 패턴(이중바닥·헤드앤숄더·삼각수렴 등)에 관심이 있는 투자자, 기술적 분석을 직접 학습하는 트레이더, 과거 사례 통계를 도구로 참고하고자 하는 사용자에게 유용합니다.

매매 의사결정은 항상 사용자 본인이 내리며, Draw2Trade는 분석을 보조하는 도구로 작동합니다.

Q매매 시그널이나 종목 추천을 받을 수 있나요?▶

제공하지 않습니다. Draw2Trade는 "지금 매수하세요" 같은 시점·종목 추천이나 시그널 메시지를 보내지 않습니다.

유사 종목 검색 결과는 "사용자가 그린 모양과 수학적으로 닮은 과거 사례" 일 뿐, 매수·매도 판단을 담고 있지 않습니다.

법적 지위

QDraw2Trade는 자본시장법상 어떤 사업으로 분류되나요?▶

Draw2Trade는 자본시장법상 투자자문업·유사투자자문업·투자일임업 어디에도 해당하지 않습니다.

본질이 "사용자가 스스로 분석하는 데 사용하는 차트 도구·검색 엔진"이며, 특정 종목에 대한 투자판단(매매 시점·가격·종목)을 자문하지 않기 때문입니다. Microsoft Excel, TradingView, HTS(영웅문 등) 같은 분석 도구와 동일한 카테고리입니다.

참고: 본 답변은 자본시장법의 일반적 해석이며, 구체적 사업 운영에 대한 법적 자문은 변호사·법무법인의 자문을 권장합니다.
Q"투자자문업"과 "유사투자자문업(=투자정보제공업)"이 정확히 무엇인가요?▶
구분정의등록·신고
투자자문업
(자본시장법 §6)		 특정 금융투자상품에 대한 투자판단(종목·매매 시점·가격 등)을 자문하는 영업 금융위 인가 필수
유사투자자문업
(=투자정보제공업, §101)		 불특정 다수에게 정기·유료로 투자판단 자문이나 종목 추천을 제공하는 영업 금융위 신고 필수

핵심은 "투자판단(매매 시점·종목·가격)에 대한 자문 제공" 여부입니다. Draw2Trade는 자문이나 추천을 하지 않고 사용자 분석 도구만 제공합니다.

QDraw2Trade는 왜 위 두 영역에 해당하지 않나요? (구체적 근거)▶

다음 7가지가 모두 부재하기 때문입니다:

  • 특정 종목 매수/매도 추천 — 없음
  • 매매 시점·가격 자문 — 없음
  • 목표 수익률·승률 약속 — 없음 (과거 통계만 표시)
  • 회사가 작성한 종목 코멘터리·리포트 — 없음 (사용자가 직접 그림)
  • 유료 시그널·VIP 채팅방 — 없음
  • 불특정 다수에게 매매 추천 정기 발송 — 없음
  • 사용자 자산 직접 운용 — 없음 (계좌 개입 없음)

또한 자본시장법 시행령 제7조는 "통계자료·기술적 분석 결과 등 객관적 자료의 단순 제공"을 규제 대상에서 명시적으로 제외합니다.

Q도구 결과를 보고 매매했다가 손실이 나면 회사가 책임지나요?▶

책임은 전적으로 이용자 본인에게 있습니다.

Draw2Trade는 차트앱 푸터에 다음과 같이 명시하고 있습니다:

본 서비스는 투자 참고용 정보 제공을 목적으로 하며, 투자 권유 또는 자본시장법상 투자자문에 해당하지 않습니다. 제공되는 패턴 유사도 분석은 과거 데이터 기반이며 미래 수익을 보장하지 않습니다. 투자 결과에 대한 책임은 전적으로 이용자에게 있습니다.

엑셀로 주가를 분석한 사용자가 손실을 봤을 때 Microsoft가 책임지지 않는 것과 같은 원리입니다.

요금·결제

QPRO 요금제는 무엇을 제공하나요?▶

PRO는 도구 기능 사용권을 확장합니다. 자세한 항목은 요금제 페이지에서 확인하실 수 있습니다.

대표적인 차이는: 유사 종목 검색 결과 수 확장, 자동 분석(Auto-Analysis) 기능, 우선 응답 등입니다.

QPRO 결제 시 자문 서비스가 제공되나요?▶

아닙니다. PRO는 도구 사용권 결제이며, 회사가 사용자에게 매매 추천이나 투자판단 자문을 보내지 않습니다.

Adobe Photoshop의 유료 구독이 사용자에게 디자인 의견을 보내지 않는 것과 같은 모델입니다. PRO 사용자 역시 분석과 판단은 본인이 수행합니다.

기능 / 알고리즘

Q"유사 종목 검색"은 어떤 알고리즘으로 작동하나요?▶

다음 3단계로 작동합니다:

  • ① 사용자가 그린 곡선을 0~1 범위로 정규화
  • ② 후보 종목들의 과거 가격 시계열에서 길이별로 슬라이딩 윈도우를 만들어 동일하게 정규화
  • ③ 형태 유사도 점수(피어슨 상관·모양 가중치·변동성 가중치 등 결합)를 계산해 상위 결과 반환

본질적으로 이미지 유사도 검색을 시계열에 적용한 것이며, 결과는 "닮은 과거 사례"이지 "미래 예측"이 아닙니다.

Q"패턴 매칭"이 미래 수익을 보장하나요?▶

보장하지 않습니다. 과거의 유사 패턴이 미래에도 같은 방향으로 움직인다는 보장은 어떤 시장에도 존재하지 않습니다.

유사 종목 결과는 "이런 모양은 과거에 N번 나타났고 그 뒤로 평균 X% 움직였다"는 과거 통계일 뿐, 미래 가격을 예측·약속하는 것이 아닙니다.

Q"자동 분석"은 어떤 기능인가요?▶

차트에서 사용자가 시작 날짜 한 점만 클릭하면, 그 시점부터 오늘까지의 가격 흐름을 자동으로 패턴화하여 유사 종목 검색의 입력으로 사용하는 PRO 기능입니다.

"종목을 추천하는" 기능이 아니라 "사용자가 직접 그리는 패턴 그리기 단계를 자동화"하는 도구입니다.
